# Auditing and Mitigating Hallucinatory Biases in VLMs

Official code repository for the paper:
**"How Can Hallucinatory Biases Be Effectively Audited and Mitigated in Vision-Language Models?"**

## Structure
- `mse_audit.py`: Multimodal Semantic Entropy (MSE) computation.
- `acls_mitigation.py`: Adaptive Contrastive Logit Subtraction (ACLS) and ACLS-Lite.
- `evaluation.py`: Benchmark evaluation scripts (CHAIR, POPE, BDI).
- `utils.py`: Helper functions and COCO object vocabulary.
